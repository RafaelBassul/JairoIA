Cai na prova

Como é inviável achar a melhor rota, algoritmos de otimização como o AG entregam uma boa rota, sem garantir que seja a melhor slide 8. Por isso se diz que o AG gera uma solução heurística.

Ideia central

Evolução como método de busca

Algoritmos genéticos são uma classe de algoritmos de busca e otimização inspirados na seleção natural e na genética slides 5–6. Servem para achar soluções ótimas ou satisfatórias em espaços de busca enormes.

Pela teoria de Darwin, a seleção favorece os indivíduos mais aptos, que têm mais chance de se reproduzir. No AG isso vira código: soluções são cromossomos artificiais, e as melhores passam adiante mais vezes.

Como representar um indivíduo

Cada problema pede uma codificação. Os slides citam cadeias binárias (a mais comum), strings de caracteres, inteiros e reais. No caixeiro viajante a representação natural é uma permutação: a ordem em que as cidades são visitadas.

3. Seleção dos pais slides 11–14

Seleção escolhe quem vai se reproduzir. Há vários métodos, e todos seguem a mesma ideia: aptidão alta dá mais chance, mas ninguém fica com chance zero (exceto no caso extremo do rank).

Roleta

A probabilidade de cada indivíduo é proporcional à sua aptidão: soma-se todos os fitness e divide-se o fitness de cada um pela soma. Depois gira-se a roleta.

Rank (ranking)

Em vez de usar o valor do fitness, ordena-se do melhor para o pior e usa-se a posição. Se um indivíduo for muito melhor que os outros, ele não domina tudo slides 12–13

pmax = s ÷ N    pmin = (2 − s) ÷ N
pi = pmin + [(N − posiçãoi) ÷ (N − 1)] × (pmax − pmin)

s é a pressão seletiva, entre 1 e 2. N é o tamanho da população. Com s=1 todos têm a mesma chance (1/N). Com s=2 a pressão é máxima: pmax=2/N e pmin=0.

Torneio

É a forma mais simples de escolher pais: uma mini-competição entre k indivíduos sorteados slide 14

  1. Sorteie k indivíduos da população, ao acaso e sem repetir (no código: random.sample(population, k)).
  2. Compare o fitness só entre esses k. Quem está fora do sorteio não participa desta rodada.
  3. O de maior fitness vence e vira pai (no código: max(selected, key=fitness)). Não há sorte nessa etapa: a sorte está só em quem foi sorteado.
  4. Devolva todos à população e repita. Para 2 pais, são 2 torneios, e o mesmo indivíduo pode vencer os dois.

Como só importa quem é maior, e não quanto, o torneio funciona igual com fitness de 0,019 ou de 1000. É por isso que o slide diz que ele é mais robusto que a roleta.

Vantagens

  • Simples de implementar.
  • Controla a pressão seletiva pelo k.
  • Mais robusto que a roleta: não depende da escala do fitness.

Desvantagens

  • k muito grande: converge rápido demais e perde diversidade.
  • k muito pequeno: pressão baixa, quase aleatório.
Qual a chance de cada indivíduo vencer? (cálculo)

Ordene a população do 1º (melhor) ao N-ésimo (pior). O indivíduo de posição r só vence se for sorteado e os outros k − 1 sorteados forem todos piores que ele. Existem N − r indivíduos piores, então:

P(vencer) = C(N − r, k − 1) ÷ C(N, k)

C(a, b) é o número de combinações de a elementos tomados b a b. Exemplo com N = 8 e k = 2 (C(8, 2) = 28 duplas possíveis):

  • 1º colocado: C(7, 1) ÷ 28 = 7 ÷ 28 = 25%
  • 2º colocado: C(6, 1) ÷ 28 = 6 ÷ 28 ≈ 21,4%
  • 8º colocado: C(0, 1) ÷ 28 = 0%. Com k ≥ 2, o pior nunca vence.

Com k = 1 a fórmula dá 1 ÷ N para todos (sorteio puro). Quanto maior o k, mais a chance se concentra nos primeiros. Esse é o controle de pressão seletiva que o slide cita.

4. Crossover (recombinação) slides 15–16, 26

O crossover combina partes dos cromossomos de dois pais para gerar filhos. O objetivo é criar descendentes que herdem trechos bons dos dois.

Na rota do caixeiro, filho precisa ser uma rota válida: cada cidade exatamente uma vez. Por isso não se pode simplesmente cortar e colar. O método dos slides é o crossover de ordem (OX):

  1. Sorteia dois cortes i < j.
  2. Copia o trecho entre os cortes do pai 1 para o mesmo lugar no filho.
  3. Percorre o pai 2 de forma circular, a partir do ponto j, e vai colocando no filho as cidades que ainda não estão nele.

5. Mutação slides 17, 28

A mutação faz pequenas alterações ao acaso para manter a diversidade genética. Sem ela, a população pode ficar toda parecida e parar de evoluir. Depois de cada mutação, a aptidão é calculada de novo. Três formas, partindo de A→B→C→D:

  • Swap (troca): duas cidades trocam de lugar. A B C D → A D C B (B e D trocaram).
  • Inversão: um trecho da rota é invertido. A [B C D] → A [D C B].
  • Deslocamento: uma cidade é movida para outra posição, e as demais se ajustam. Mover C para o início: C A B D.

6. Repetição, parada e resultado slides 18–19

O processo se repete por várias gerações. Em cada uma: avaliação → seleção → crossover → mutação → formação da nova geração. Ele termina quando uma condição de parada é atendida:

Número máximo de gerações
Para ao atingir o número definido, mesmo que as soluções ainda sejam ruins.
Limiar de aptidão
Para quando a melhor solução atinge ou passa de um valor definido.
Estagnação
Para se a melhor aptidão não melhora de forma significativa depois de certo número de gerações.

Resultado: o AG devolve a rota de melhor aptidão (menor distância) da última geração. Ele não garante que ela seja a melhor possível, porque muitas rotas nunca foram testadas ou foram descartadas pelo caminho.

Distância e aptidão slide 24

# Função para calcular a distância total de uma rota
def Distancia_total_rota(route):
    total_distance = 0
    for i in range(len(route) - 1):
        total_distance += distances[route[i]][route[i + 1]]
    # Retornar ao ponto inicial
    total_distance += distances[route[-1]][route[0]]
    return total_distance

# Função de aptidão (fitness)
def fitness(route):
    return 1 / Distancia_total_rota(route)  # Quanto menor a distância, maior a aptidão
  • O for soma cada trecho consecutivo da rota. Com range(len(route) - 1) ele para no penúltimo índice, para poder olhar route[i + 1].
  • route[-1] é a última cidade e route[0] é a primeira: essa linha fecha o ciclo (a volta à origem). Por isso a lista não precisa repetir a cidade inicial no fim.
  • O fitness é o inverso da distância, então a maior aptidão é a menor distância.
  • Para uma rota 4 cidades [0,1,2,3] nessa matriz: 12 + 15 + 10 + 30 (volta) = 67.

Indivíduo aleatório e seleção por torneio slide 25

def create_individual():
    individual = list(range(len(distances)))  # [0, 1, 2, 3, 4, 5, 6] representando as cidades
    random.shuffle(individual)
    return individual

# Seleção por torneio
def Selecao_por_torneio(population):
    selected = random.sample(population, Qtd_elementos_torneio)
    return max(selected, key=fitness)  # Seleciona o indivíduo com maior aptidão
  • len(distances) vale 7, então range(7) gera 0 a 6, os índices das cidades A a G.
  • list(...) transforma esses números numa lista, e random.shuffle a embaralha. Resultado: uma permutação, ou seja, uma rota válida sem repetição.
  • random.sample(population, k) sorteia k indivíduos diferentes. max(..., key=fitness) escolhe o de maior aptidão entre eles.

Crossover de ordem (OX) slides 26–27

# Crossover de ordem (OX)
def crossover(pai1, pai2):
    size = len(pai1)
    start, end = sorted(random.sample(range(size), 2))
    child = [-1] * size
    child[start:end] = pai1[start:end]
    pointer = end
    for i in range(size):
        if pai2[(end + i) % size] not in child:
            child[pointer % size] = pai2[(end + i) % size]
            pointer += 1
    return child
  • sorted(random.sample(range(size), 2)) sorteia dois cortes diferentes e os coloca em ordem: start < end.
  • child = [-1] * size cria o filho vazio (-1 significa “vaga livre”).
  • child[start:end] = pai1[start:end] copia o trecho do pai 1. Lembre: o fatiamento do Python não inclui a posição end.
  • (end + i) % size anda pelo pai 2 de forma circular: ao chegar no fim da lista, o resto da divisão faz voltar ao índice 0. O slide 26 mostra a tabela (5+0)%8=5, …, (5+3)%8=0.
  • Só entra no filho a cidade que not in child. O pointer marca a próxima vaga a preencher, também de forma circular.

Mutação por troca slide 28

# Mutação (troca de dois pontos na rota)
def mutacao(route):
    if random.random() < Taxa_mutacao:
        idx1, idx2 = random.sample(range(len(route)), 2)
        route[idx1], route[idx2] = route[idx2], route[idx1]
  • random.random() devolve um número entre 0 e 1. Com Taxa_mutacao = 0.3, ele é menor que 0,3 em cerca de 30% das vezes. Nos outros 70% a função não faz nada.
  • random.sample(range(len(route)), 2) escolhe dois índices distintos.
  • A troca em uma linha só funciona em Python graças à atribuição múltipla. A função altera a lista no lugar, sem return.

O algoritmo completo slide 27

# Algoritmo Genético
def genetic_algorithm():
    # Inicialização da população
    population = [create_individual() for _ in range(Tamanho_populacao)]

    for generation in range(Qtd_geracoes):
        # Avaliação da população
        population = sorted(population, key=fitness, reverse=True)

        # Seleção e reprodução
        new_population = []
        for _ in range(Tamanho_populacao):
            parent1 = Selecao_por_torneio(population)
            parent2 = Selecao_por_torneio(population)
            child = crossover(parent1, parent2)  # Apenas um filho é gerado
            mutacao(child)
            new_population.append(child)

        # Substituição da população
        population = new_population

    # Retornar a melhor e a pior solução
    melhor_individuo = max(population, key=fitness)
    pior_individuo = min(population, key=fitness)
    return melhor_individuo, Distancia_total_rota(melhor_individuo), pior_individuo, Distancia_total_rota(pior_individuo)
  • Cada comentário do código corresponde a uma etapa do ciclo: inicialização, avaliação, seleção, reprodução, substituição.
  • Cada geração cria exatamente Tamanho_populacao filhos (um filho por par de pais), e a população antiga é inteiramente substituída. Não há elitismo, ou seja, o melhor indivíduo não é guardado. Por isso a melhor distância pode até piorar de uma geração para outra.
  • O sorted do início não é obrigatório para o torneio funcionar (ele sorteia ao acaso); é só uma organização da população.

def Selecao_por_roleta(population):
    # 1) Calcula o fitness de cada indivíduo
    pesos = [fitness(ind) for ind in population]
    total = sum(pesos)

    # 2) Sorteia um ponto na roleta [0, total)
    r = random.random() * total

    # 3) Varre manualmente, sem zip
    acumulado = 0.0
    for i in range(len(population)):
        acumulado += pesos[i]  # soma o fitness do indivíduo i
        if r <= acumulado:     # achamos o intervalo onde r caiu
            return population[i]
  • Pense numa fita de comprimento total dividida em fatias. A fatia de cada indivíduo tem tamanho igual ao seu fitness.
  • r é um ponto sorteado na fita. O laço soma fatia por fatia e para na primeira em que o acumulado alcança r. Quem tem fatia maior é sorteado mais vezes.

Parte 2 · Árvores de decisão

O que é uma árvore de decisão

Uma árvore de decisão é uma estrutura hierárquica que traduz uma sequência de decisões. Um dado entra pelo nó raiz, no topo, e desce até chegar a um nó folha, que guarda o resultado: uma classe ou um valor slide 4. Existe um único caminho da raiz até cada folha, e esse caminho é a regra usada para classificar o dado slide 5.

Os tipos de nó slide 5

Nó de decisão (quadrado)Indica uma decisão a ser tomada. Você escolhe o ramo.
Nó de probabilidade (círculo)Indica as probabilidades de certos resultados. O acaso escolhe o ramo.
Nó de término (triângulo, folha)Contém a decisão ou o resultado: a classe (classificação) ou o valor (regressão).

As arestas (ramos) ligam os nós e representam as respostas às perguntas, por exemplo sim ou não. Nos exemplos de IA, cada nó interno faz uma pergunta sobre uma característica dos dados slides 5, 44–45.

Algoritmos: CART e ID3 slide 48

A árvore é só uma estrutura. O que usa aprendizado de máquina é o algoritmo que a monta:

CART (Classification and Regression Trees)
  • Usado em regressão e classificação.
  • Implementado no scikit-learn (DecisionTreeRegressor).
  • Sempre cria árvores binárias, mesmo com várias classes.

  • Usado em classificação.
  • Permite árvores não binárias (um ramo por valor do atributo).

  • Detecção de fraudes: transações suspeitas a partir de padrões de comportamento.
  • Diagnóstico médico: decisões baseadas em sintomas e exames.
  • Marketing: segmentar consumidores por características demográficas e comportamentais.
Árvore com probabilidades

Decisão sob incerteza: valor esperado

Aqui a árvore ajuda a visualizar e calcular o resultado de uma série de escolhas, considerando a probabilidade de cada evento slide 6. Ela é formada por nós de decisão, nós de chance (eventos aleatórios com probabilidades conhecidas) e nós terminais com os resultados finais.

Como construir slides 8–11

  1. Comece com uma decisão principal: um quadrado, com uma linha à direita para cada solução ou ação possível. Rotule as linhas.
  2. Expanda: se outra decisão for necessária, desenhe outro quadrado. Se o resultado for incerto, desenhe um círculo (nó de probabilidade). Se o problema estiver resolvido, deixe em branco por enquanto.
  3. De cada círculo, desenhe linhas para os resultados possíveis. Para analisar numericamente, inclua a probabilidade de cada resultado e o custo de cada ação.
  4. Continue até cada linha chegar a um desfecho (sem mais escolhas nem resultados prováveis). Atribua um valor a cada desfecho (uma pontuação ou um valor financeiro) e marque com um triângulo.

Como analisar slides 12–13

Ao calcular a utilidade esperada de cada escolha, você minimiza o risco e maximiza a chance de um resultado desejável. Os benefícios esperados são a soma dos valores de todos os resultados possíveis, cada um multiplicado pela sua probabilidade. Depois subtrai-se o custo da decisão.

Utilidade esperada = Σ (probabilidade × valor) − custo da decisão

Árvore de classificação

Entropia e ganho de informação

Na classificação, a árvore aprende a dividir os dados de modo que, em cada nó final, os exemplos sejam majoritariamente de uma mesma classe, maximizando a pureza dos nós. O critério para escolher onde dividir é a entropia e o ganho de informação slide 26.

O algoritmo ID3 segue os mesmos passos do CART, mas em vez do SSE usa a entropia e “olha” para qual atributo fornece a melhor entropia slide 49.

Entropia slides 49–52

H(D) = − Σ p(i) · log₂( p(i) )
  • p(i) é a probabilidade (proporção) da classe i no conjunto.
  • A entropia mede a incerteza ou desordem do conjunto: “quão difícil é determinar uma classe”. Quanto menor, mais previsível é o resultado.
  • Entropia 0: todas as instâncias são da mesma classe (conjunto puro, máxima previsibilidade).
  • Em problemas binários a entropia vai de 0 a 1. O valor 1 significa classes com a mesma probabilidade (máxima incerteza).
  • Com várias classes ela pode passar de 1. A entropia máxima é log₂(c), onde c é o número de classes.

Por que há um sinal negativo na fórmula? Para 0 < p < 1, o log₂(p) é negativo (log₂ 0,5 = −1; log₂ 0,25 = −2), logo o produto p·log₂(p) também é. O sinal negativo de fora transforma a soma de valores negativos em um resultado positivo slide 51.

Entropia da árvore e ganho de informação slides 53–57

Dividir os dados por um atributo cria ramos, e cada ramo tem a sua entropia. A entropia da árvore (do conjunto após a divisão) é a média das entropias dos ramos, ponderada pela proporção de exemplos de cada um:

Entropia da árvore = p₁ · H(ramo₁) + p₂ · H(ramo₂) + … + pₙ · H(ramoₙ)
GI = H − H(D_a)   (ganho = entropia inicial − entropia da árvore)

Exemplo do slide: 30 pessoas, 15 homens e 15 mulheres. Pergunta “idade < 20?”.

Árvore de regressão

Regressão: dividir para minimizar o SSE

Na regressão, o alvo é um valor numérico contínuo. A árvore aprende a “dividir os dados” para que, em cada nó final, os valores de Y fiquem o mais próximo possível do valor real. O critério para decidir onde dividir é o SSE (soma das distâncias quadráticas) slide 25.

SSE = Σ ( yᵢ − ŷ )²    ŷ = média do grupo

Passo a passo slide 29

  1. Para cada variável independente, testam-se pontos de corte: valores intermediários entre pares de observações distintas (o ponto médio).
  2. Em cada corte, os dados se dividem em dois grupos: valores menores ou iguais ao corte vão para o ramo esquerdo, e os maiores para o direito.
  3. Calcula-se a média e o SSE de cada grupo, e o SSE total (esquerda + direita).
  4. Escolhe-se o corte que minimiza o SSE total.
  5. Repete-se recursivamente em cada nó até um critério de parada: melhora pouco o SSE, profundidade máxima ou número mínimo de elementos no grupo.

Valor previsto em cada folha: a média dos valores-alvo que caíram nela slide 27.

Cuidados com as árvores

Poda, profundidade e quando parar

Poda (pruning) slides 43, 62

A poda remove nós desnecessários depois que a árvore foi construída. Ela corta ramos que usam atributos com pouco impacto na melhora do modelo, ou seja, que não têm poder preditivo suficiente. A poda serve para combater o overfitting.

A poda deve ser feita:

  • Quando a diferença entre os dois filhos de um nó é pequena ou nula.
  • Quando dividir o nó não reduz significativamente o erro.
  • Quando os valores médios dos grupos são iguais ou muito próximos.

Aumentar a profundidade muitas vezes não traz ganho de informação, como no exemplo da idade.

Profundidade máxima e critérios de parada slides 60–62

  • Profundidade máxima: controla a complexidade e evita overfitting. Árvores profundas captam relações mais complexas, mas se ajustam demais aos dados de treino e perdem a capacidade de generalizar.
  • Conjuntos pequenos: árvores mais rasas (por exemplo, profundidade de 3 a 5).
  • Conjuntos grandes: a árvore pode ser mais profunda e explorar relações mais complexas.
  • Quantidade de parâmetros (atributos): poucos parâmetros pedem árvores rasas; muitos, árvores mais profundas.
  • Critérios de parada: além da profundidade máxima, o número mínimo de amostras para dividir um nó.
  • Na classificação, também se para quando o nó é puro (entropia 0) ou quando acabam os atributos. Na regressão, quando a divisão melhora pouco o SSE.

Vantagens e desvantagens slides 46–47, 58–59

Vantagens

  • Interpretabilidade: regras “se… então…” fáceis de explicar.
  • Flexibilidade: servem para classificação e regressão.
  • Pouco processamento de dados: não exigem normalização nem padronização.
  • Dados categóricos e numéricos: lidam com os dois, sem codificação extra.

Desvantagens

  • Overfitting: árvore muito profunda se ajusta demais ao treino. Combate-se com poda.
  • Instabilidade: pequenas mudanças nos dados podem gerar árvores bem diferentes.
  • Problemas muito complexos: com muitas variáveis interdependentes podem ser menos eficientes que modelos como redes neurais.

YOLO (You Only Look Once, “você só olha uma vez”) é uma rede neural para detecção de objetos slide 3. Foi criada por Joseph Redmon em 2015 para detectar objetos em tempo real, como alternativa mais rápida aos métodos convencionais, que processavam a imagem em vários estágios. A inovação foi usar uma única rede neural que “olha” a imagem apenas uma vez.

Para cada objeto encontrado, a rede devolve três coisas: a caixa (bounding box) que o envolve, a classe (carro, pessoa, placa…) e a confiança (de 0 a 1).

1. Explique o papel do parâmetro --cfg e do parâmetro --hyp no processo de treinamento do YOLO. Como cada um influencia o comportamento e o desempenho da rede?

--cfg é o arquivo (.yaml) com o modelo da rede: número de camadas, tipo de blocos (CSP, SPP, PAN, convolução, maxpooling…), conexões entre camadas, número de canais e o número de classes (nc). Ele decide se a rede será mais enxuta ou mais profunda.

  • Rede maior: mais capacidade e potencial de acurácia, mas mais memória, treino e inferência mais lentos (menos fps) e mais risco de overfitting com poucos dados.
  • Rede menor: mais rápida e leve, porém com menos capacidade.
  • Para o seu treino, o ajuste mínimo é o nc igual ao número de classes.

--hyp é o arquivo de hiperparâmetros: valores que o usuário define antes do treino e que a rede não aprende. Eles controlam como a rede aprende: pesos e limiares do cálculo do erro (obj, cls_pw, iou_t…) e o aumento de dados (variação de cor, rotação, translação, escala, espelhamento, mosaico).

  • Mais aumento de dados: a rede vê mais variações e tende a generalizar melhor (menos overfitting), mas o treino fica mais lento e “difícil”.
  • Pesos do erro: mudam o quanto a rede se preocupa com a caixa, com a presença de objeto e com a classe.
  • Os valores padrão costumam servir.

Resumindo: o cfg define a estrutura da rede; o hyp define as regras do treinamento.

2. Explique para que serve o parâmetro --conf, utilizado na fase de validação e detecção, e como ele se relaciona com métricas como precision, recall e mAP.

--conf é o limiar de confiança (threshold): a rede só considera detecções com confiança maior ou igual a esse valor.

  • Precision = TP ÷ (TP + FP): das detecções que a rede fez, quantas estavam certas.
  • Recall = TP ÷ (TP + FN): dos objetos que existiam, quantos a rede achou.
  • Conf alto: poucas detecções, quase todas certas. A precision sobe e o recall cai (objetos são perdidos).
  • Conf baixo: muitas detecções, inclusive falsas. O recall sobe e a precision cai.
  • AP é a área sob a curva precision × recall de uma classe, e o mAP é a média do AP das classes. Como a curva é obtida variando o limiar, na validação usa-se um conf bem baixo (o slide 13 usa 0,001), para a curva cobrir todos os pontos. Em produção, escolhe-se o conf que dá o equilíbrio desejado entre precision e recall.

Precision, recall e mAP não aparecem nos slides; a explicação é a definição padrão. Use o laboratório de confiança na parte 3 para ver precision e recall mudarem.

3. Explique para que serve o parâmetro --iou, utilizado na fase de validação e detecção.

IoU (Intersection over Union) é a área da interseção de duas caixas dividida pela área da união: vale 0 quando não se tocam e 1 quando coincidem. No slide 23, o --iou “define qual o percentual da imagem deve estar dentro do bounding box para considerar a detecção”.

Na prática ele é o limiar usado para comparar caixas:

  • Remover duplicatas: se duas caixas previstas para o mesmo objeto têm IoU acima do limiar, mantém-se só a de maior confiança.
  • Validar: uma detecção só conta como acerto se a sua caixa tiver IoU suficiente com a caixa rotulada (é o que está por trás de AP₅₀ e AP₇₅).

Valor alto (0,7): exige caixas bem sobrepostas. Valor baixo: aceita sobreposição pequena.

5. Considerando a rede YOLO (v7/v9), explique o que é uma época.

Uma época é uma passagem completa de todas as imagens do conjunto de treino pela rede. Como as imagens entram em lotes (--batch-size), uma época tem nº de imagens ÷ batch iterações. Exemplo: 1.000 imagens com batch 8 dão 125 iterações por época.

O treino roda várias épocas (opção --epochs). Poucas épocas deixam a rede subtreinada; épocas demais podem causar overfitting. A validação ao fim de cada época mostra quando o desempenho para de melhorar.

8. Após várias horas treinando um modelo na YOLOv9, sua máquina trava e você precisa reiniciá-la. O que deve ser feito para não ser necessário começar o treinamento do zero?

Durante o treino o YOLO salva checkpoints na pasta de resultados (por exemplo runs/train/<name>/weights/): o last.pt, atualizado a cada época, e o best.pt, o melhor até o momento. Depois de reiniciar:

  1. Não apague a pasta de resultados.
  2. Retome o treino apontando para o último checkpoint, com --resume: python3 train.py --resume runs/train/<name>/weights/last.pt. O last.pt guarda os pesos, o estado do otimizador e a época em que parou, então o treino continua de onde parou.
  3. Alternativa: usar o last.pt como --weights de um novo treino. Isso aproveita os pesos, mas reinicia o cronograma de épocas.

Não está nos slides; a sintaxe exata pode variar um pouco entre as versões. Em ambientes como o Colab, salve a pasta de resultados no Google Drive para não perdê-la.

9. Como é feito um “teste de sanidade” em um modelo de rede neural e por que ele é utilizado?

É uma verificação rápida de que a rede e o pipeline estão corretos antes de gastar horas treinando. A forma mais comum: treinar com um conjunto minúsculo (um lote, ou 5 a 10 imagens) por várias épocas. Uma rede saudável consegue decorar esses poucos exemplos: a perda cai quase a zero e o acerto sobe a quase 100%.

  • Se não decora, há um erro: rótulos errados, caminhos ou nc incorretos, pré-processamento, taxa de aprendizado ruim ou bug no código.
  • Outros testes parecidos: conferir se a perda inicial é compatível com um palpite aleatório, e desenhar os rótulos sobre as imagens para ver se as caixas batem.

Não está nos slides; é o procedimento padrão de depuração de redes neurais.

10. No Google Colab, com GPU limitada, um aluno aumenta o --batch-size de 4 para 32. Quais as implicações?

--batch-size é quantas imagens são usadas de cada vez (slide 14). Passar de 4 para 32 multiplica por 8 as imagens na GPU ao mesmo tempo:

  • Memória: o consumo de memória da GPU sobe bastante. Em uma GPU limitada é provável o erro “CUDA out of memory” e o treino parar.
  • Se couber: cada época tem menos iterações e costuma terminar mais rápido, e o gradiente de cada atualização é mais estável (menos ruído).
  • Em compensação há menos atualizações dos pesos por época, e pode ser preciso ajustar a taxa de aprendizado.
  • Alternativas se faltar memória: voltar para um batch menor, diminuir --img ou escolher uma rede menor (--cfg).

2. Explique o que é ENTROPIA, GANHO DE INFORMAÇÃO e NÓ PURO, no contexto de árvores de classificação.
  • Entropia: mede a incerteza (desordem) de um conjunto: H = −Σ p(i)·log₂ p(i). É 0 quando todos são da mesma classe e vale 1 (em problemas binários) quando as classes são igualmente prováveis. Com c classes, o máximo é log₂(c).
  • Ganho de informação: quanto a incerteza cai ao dividir o conjunto por um atributo: GI = entropia inicial − entropia ponderada dos ramos. GI alto indica um atributo muito informativo. O algoritmo escolhe o atributo de maior ganho.
  • Nó puro: nó em que todos os exemplos pertencem à mesma classe. Tem entropia 0, não precisa mais ser dividido e vira folha.

Exemplo (slide 69): no jogo de tênis, a entropia inicial é 0,940 e dividir por Tempo dá entropia ponderada 0,693, ganho de 0,247. O ramo “nublado” (4 sim, 0 não) é um nó puro.

3. A poda (pruning) é essencial para evitar overfitting. Explique quando uma árvore deve ser podada e quais critérios podem ser usados para definir a altura máxima da árvore.

Poda é remover nós desnecessários depois que a árvore foi construída. Ela deve ser feita quando:

  • a diferença entre os dois filhos de um nó é pequena ou nula;
  • dividir o nó não reduz significativamente o erro;
  • os valores médios dos grupos são iguais ou muito próximos.

Critérios para a altura máxima (slides 60–62):

  • Tamanho do conjunto de dados: conjuntos pequenos pedem árvores rasas (por exemplo, profundidade 3 a 5); conjuntos grandes permitem mais profundidade.
  • Quantidade de atributos: poucos atributos, árvores rasas; muitos, mais profundas.
  • Outros critérios de parada: número mínimo de amostras para dividir um nó e a redução mínima do erro (SSE ou entropia) que uma divisão precisa trazer.
4. Em árvores de regressão, qual critério é usado para definir a separação dos ramos do próximo nível da árvore?

O SSE (soma dos erros quadráticos). Testam-se os pontos de corte (pontos médios entre valores distintos). Para cada corte, calcula-se o SSE de cada grupo em relação à sua média e soma-se: SSE total = SSE esquerdo + SSE direito. Escolhe-se o corte de menor SSE total. Exemplo (slides 30–33): para as horas estudadas, o corte 4,5 dá 98 + 162 = 260, o menor entre os testados.

5. Em árvores de classificação, qual o critério usado para definir a separação dos ramos do próximo nível da árvore?

A entropia e o ganho de informação. Para cada atributo disponível, calcula-se a entropia de cada ramo que ele geraria e a entropia ponderada da divisão. Escolhe-se o atributo de maior ganho (que é o de menor entropia ponderada). Existem variações com o índice de Gini ou o erro de classificação (slide 27), mas o critério dos slides é a entropia.

6. Quais critérios de parada podem ser usados em uma árvore de decisão de classificação?
  • Nó puro: todos os exemplos da mesma classe (entropia 0).
  • Sem atributos para dividir: usa-se a classe da maioria na folha.
  • Profundidade máxima atingida.
  • Número mínimo de amostras para dividir um nó.
  • Ganho de informação insuficiente: a divisão quase não reduz a entropia.
  • Depois da construção, a poda remove o que não traz poder preditivo.

Os slides citam profundidade máxima, número mínimo de amostras e poda (slide 62). Os outros são os critérios naturais do algoritmo.

7. Para montar uma árvore de decisão para um conjunto de dados pequeno, você optaria por uma árvore rasa ou profunda? Por quê?

Uma árvore rasa (o slide 60 sugere profundidade de 3 a 5). Com poucos dados, uma árvore profunda acaba com folhas de 1 ou 2 exemplos: ela decora o conjunto de treino (overfitting) e generaliza mal para dados novos. Uma árvore rasa é mais simples, mais estável e mais fácil de interpretar.

8. Cite 3 vantagens e 3 desvantagens das árvores de regressão e classificação.

Vantagens

  • Interpretabilidade: regras “se… então…” fáceis de explicar.
  • Flexibilidade: servem para classificação e regressão.
  • Pouco pré-processamento: não exigem normalização nem padronização (e lidam com dados categóricos e numéricos).

Desvantagens

  • Propensão ao overfitting quando ficam muito profundas (combate-se com poda).
  • Instabilidade: pequenas mudanças nos dados geram árvores bem diferentes.
  • Não lidam bem com problemas muito complexos, com muitas variáveis interdependentes (redes neurais podem ser melhores).

Algoritmos genéticos

1. Algoritmos genéticos são algoritmos heurísticos. Explique o que isso significa.

Uma heurística busca uma solução boa em tempo razoável, mas sem garantia de que seja a melhor. O AG não testa todas as soluções (no caixeiro viajante seriam (n−1)! rotas, impraticável para n grande): ele explora uma parte do espaço de busca, guiado pela aptidão e por sorteios. Por isso pode devolver uma ótima solução, mas não prova que ela é a ótima (slides 5 e 19).

3. Descreva como a teoria de Darwin inspira o funcionamento dos algoritmos genéticos.

Pela teoria de Darwin, a seleção natural favorece os indivíduos mais aptos, que têm mais chance de se reproduzir e passar suas características adiante (slide 6). No AG:

  • Indivíduos são cromossomos artificiais que representam soluções (no caixeiro viajante, rotas).
  • Aptidão (fitness) mede quão boa é cada solução.
  • Seleção escolhe os pais favorecendo os mais aptos.
  • Crossover (reprodução) combina genes de dois pais e gera filhos.
  • Mutação introduz variações aleatórias, como as mutações genéticas.
  • Gerações se sucedem e a população vai melhorando.
4. O que é a função de aptidão (fitness) e qual o seu papel dentro de um algoritmo genético?

É a função que mede quão boa é uma solução candidata para o problema (slide 10). No caixeiro viajante, é o inverso da distância total: fitness = 1 ÷ distância, então rota curta tem aptidão alta (P₂ = 47 → 0,02128; P₁ = 52 → 0,01923; P₃ = 61 → 0,01639).

Papel: transforma a qualidade em um número que alimenta a seleção. Na roleta define o tamanho da fatia, no rank define a posição e no torneio decide o vencedor. Assim, geração após geração, as boas soluções têm mais descendentes e a população evolui.

5. Explique os principais tipos de mutação em problemas de otimização de rotas: swap, inversão e deslocamento.

A mutação mantém a diversidade genética e, em rotas, precisa gerar rotas válidas (sem cidade repetida). Exemplo com A→B→C→D (slide 17):

  • Swap (troca): duas cidades escolhidas ao acaso trocam de posição. Trocando B e D: A→D→C→B.
  • Inversão: um trecho da rota é invertido. O trecho [B, C, D] vira [D, C, B]: A→D→C→B.
  • Deslocamento: uma cidade é movida para outra posição e as demais se ajustam. Movendo C para o início: C→A→B→D.

Depois de cada mutação, a aptidão é recalculada. A taxa de mutação é a probabilidade de ela acontecer (30% = em cerca de 30% dos filhos).

6. Descreva três critérios diferentes de parada que podem ser utilizados em algoritmos genéticos.
  • Número máximo de gerações: para ao atingir um número definido, independentemente da qualidade das soluções.
  • Limiar de aptidão: para quando a melhor solução atinge ou ultrapassa um valor definido.
  • Estagnação: para se não houver melhora significativa da melhor aptidão depois de certo número de gerações (slide 18).
7. Um AG garante encontrar a melhor solução para o problema? Por quê?

Não. O AG é heurístico: não percorre todo o espaço de busca, depende de sorteios (população inicial, seleção, cortes, mutação) e dos parâmetros (tamanho da população, taxas, número de gerações). Muitas soluções nunca são testadas ou são descartadas ao longo do processo, e a população pode convergir para uma solução boa, porém não a melhor. Ele devolve a melhor solução encontrada, não a melhor possível (slide 19).

8. Crie um algoritmo que receba 2 pais e faça um crossover, criando um novo filho.

Crossover de ordem (OX), o do slide 27: copia um trecho do pai 1 e completa o resto com as cidades do pai 2, de forma circular, sem repetir.

import random

def crossover(pai1, pai2):
    size = len(pai1)
    start, end = sorted(random.sample(range(size), 2))   # dois cortes
    filho = [-1] * size
    filho[start:end] = pai1[start:end]                   # copia trecho do pai 1
    pointer = end
    for i in range(size):
        gene = pai2[(end + i) % size]                    # percorre o pai 2 de forma circular
        if gene not in filho:
            filho[pointer % size] = gene
            pointer += 1
    return filho

Teste: crossover([0,1,2,3,4,5,6], [6,4,5,2,0,1,3]) devolve uma rota válida de 7 cidades.

9. Crie um algoritmo que receba um elemento (rota) e faça uma mutação do tipo deslocamento.
import random

Taxa_mutacao = 0.3

def mutacao_deslocamento(rota):
    nova = rota[:]                                  # copia para não alterar a original
    if random.random() < Taxa_mutacao:
        i, j = random.sample(range(len(nova)), 2)   # posição de origem e de destino
        cidade = nova.pop(i)                        # tira a cidade da posição i
        nova.insert(j, cidade)                      # coloca na posição j
    return nova

Exemplo: com i = 2 e j = 0, A→B→C→D vira C→A→B→D.
